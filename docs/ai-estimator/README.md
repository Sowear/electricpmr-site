# ИИ-помощник электрика

## Текущий статус

В первой версии реализованы экран черновика сметы и серверный подбор работ из D1 `catalog_items`. Модель не задаёт цену; сервер берёт действующий `base_price`. Пользователь должен проверить и заполнить неизвестные количества до сохранения. Подробный аудит и ограничения: [audit.md](./audit.md).

## Настройка API

Задайте секрет для Cloudflare Worker, не добавляя его в `.env`, клиентский код или репозиторий:

```sh
wrangler secret put OPENAI_API_KEY
```

При необходимости задайте `OPENAI_MODEL` как переменную окружения Worker (значение по умолчанию в коде — `gpt-4o-mini`). Для локальной проверки настройте секрет в соответствующем локальном окружении Wrangler. API secret должен оставаться только на сервере.

Frontend должен знать URL Worker через `VITE_API_BASE_URL` (например, origin выделенного API-домена). Если Worker работает на отдельном origin, добавьте этот origin в `connect-src` Content Security Policy в `vercel.json`; для same-origin proxy это изменение не требуется. Значение должно совпадать с адресом Worker, который используется приложением для авторизации и `/api/db/*`.

Рабочий экран доступен по адресу `/estimator/assistant` пользователям с ролью менеджера или администратора. Нужны настроенный Worker, сессия приложения, заполненная таблица `catalog_items` и действующий OpenAI API key. Маршрут отвечает 503, если ключ отсутствует.

## Локальный запуск и проверки

```sh
npm install
npm run dev
npm run test
npm run build
```

Локальный сайт сам по себе не поднимает D1 Worker и не гарантирует доступность OpenAI. Настройте Wrangler и тестовую D1 базу отдельно. Не запускайте проверки записи на production данных.

Перед развёртыванием этой версии примените `cloudflare/migrations/0001_estimate_ai_context.sql` к нужной базе D1 и одноимённую миграцию Supabase, если среда использует прямой Supabase. Контекст хранит исходное описание и результат осмотра рядом со сметой; исторические сметы не требуют изменения.

## Пока отсутствует

MCP/ChatGPT интеграция, рынок ПМР, ведомость материалов, фото и голосовой осмотр, аналитика завершённых заказов и диалоговое изменение сохранённых смет. Порядок следующей реализации указан в `audit.md`.
